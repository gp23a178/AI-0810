## 別の変換を実行する
既存の結果がある保存先には上書きしません。再試行は別名を指定します。

```bash
python3 convert_tenhou_safe.py --mode S --max-games 5 --no-full-reference --output-dir tenhou_data/converted/S_retry
```

Sは5人、Mは12人、Lはmanifest内の全員です。既定seed=42で再現可能です。
`--seed 123` のように変えると選ぶ人が変わります。
`--max-games 5` は全体で最大5対局であり、1人につき5対局ではありません。
`--max-games` を省略すると条件に合う候補をすべて変換します。
人数を選んでも、その人に達成後の対局がなければ、その人のデータは0件です。

```bash
python3 convert_tenhou_safe.py --mode M --no-full-reference
python3 convert_tenhou_safe.py --mode L --no-full-reference
```

達成日の時刻は不明なので、当日も除外し翌日以降を採用します。
`--rank-policy all` は達成前を含む診断用です。使用する場合は、正式データと混ざらない別の `--output-dir` を指定してください。
ZIP内のほとんどは達成当日以前です。CSV変換に失敗しているため件数が少ないのではありません。
大規模研究には達成後の牌譜を追加収集する必要があります。

## 情報漏洩を防ぐ設計
各イベントを発生順に更新して、その時点の状態から行を作ります。
自身の手牌、公開河、ツモ切り、鳴き、点数、局、供託、リーチ、表ドラ表示牌を入力に使います。
他家のツモ牌IDは隠し、暗槓の赤牌の詳細も隠します。暗槓の牌種は公開扱いです。
裏ドラ・終局結果・未来の河・他家の非公開手牌は入力に入れません。
`target_hand_1..37` はその時点の相手の伏せた手牌で、副露・槓の牌は含みません。
学習では赤牌を通常牌に合算して34種類の枚数を予測します。
CSVは1局面×4観測者×3相手の12行です。観測者と予測対象の席番号も入力に含みます。
CSV自体には正解が含まれます。任意の全数値列で学習せず、付属コードの許可列一覧を使ってください。
旧参照用のstates_full出力は実装していません。`--no-full-reference` は互換オプションです。

対局IDは &tw= の視点指定を除いて正規化し、重複除去します。
全対局IDをseed付きハッシュ順に並べ、約20%（最低1対局）を評価側に置きます。
行数を制限するサンプリングは分割後に行い、同一対局が両側に入らないことを検査します。
独立した対局が2件未満なら学習を停止します。
テストでは隠れた配牌・他家ツモ・未来の情報を変更して入力の不変性を確認しています。
すべての形式を網羅した証明ではありません。未知形式はエラーとして監査してください。
